# Sheet: to do 📋

Персоналізований to-do застосунок із кастомізованими списками, іконками та GIF-фонами. Без фреймворків — тільки JavaScript.

## Що вміє

- **Кілька списків** — створюй окремі списки для роботи, побуту, навчання i т.д.
- **Іконки для кожного списку** — 12 тематичних іконок при створенні
- **Задачі** — додавай, відмічай виконаними та видаляй у будь-який момент
- **Лічильник прогресу** — одразу видно скільки задач вже зроблено
- **GIF-фон** — чотири атмосферних варіанти на вибір, зберігається між сесіями
- **Адаптивний дизайн** — зручно як на ноутбуці, так і на телефоні

## Технолоджії

- **JS** — жодних фреймворків, вся логіка через DOM API
- **ООП** — логіка розбита на класи: `App` керує інтерфейсом, `TaskList` і `Task` зберігають дані, `StorageManager` відповідає за збереження
- **Bootstrap Icons** — підключена бібліотека іконок для списків та інтерфейсу
- **localStorage** — дані зберігаються прямо у браузері, нічого не губиться після перезавантаження
