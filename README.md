# Sheet: to do 📋

Персоналізований to-do застосунок із кастомізованими списками, іконками та GIF-фонами. Без фреймворків — тільки JavaScript.

## Що вміє

- **Кілька списків** — створюй окремі списки для роботи, побуту, навчання i т.д.
- **Іконки для кожного списку** — 12 тематичних іконок при створенні
- **Задачі** — додавай, відмічай виконаними та видаляй у будь-який момент
- **Лічильник прогресу** — одразу видно скільки задач вже зроблено
- **GIF-фон** — чотири атмосферних варіанти на вибір, зберігається між сесіями
- **Адаптивний дизайн** — зручно як на ноутбуці, так і на телефоні

## Технології

- **JS** — жодних фреймворків, вся логіка через DOM API
- **ООП** — логіка розбита на класи: `App` керує інтерфейсом, `TaskList` і `Task` зберігають дані, `StorageManager` відповідає за збереження
- **Bootstrap Icons** — підключена бібліотека іконок для списків та інтерфейсу
- **localStorage** — дані зберігаються прямо у браузері, нічого не губиться після перезавантаження

## Локальний запуск

Проєкт використовує HTML, CSS та JavaScript без збірки.
Для запуску потрібен локальний HTTP-сервер, оскільки JavaScript використовує ES modules.

1. Завантажте проєкт через **Code → Download ZIP** та розпакуйте архів.
2. Відкрийте папку з `index.html` у VS Code.
3. Встановіть розширення **Live Server** від **Ritwick Dey**.
4. Натисніть правою кнопкою на `index.html` → **Open with Live Server**.
5. Застосунок відкриється у браузері.

Для завантаження Bootstrap Icons потрібен інтернет.

### Перевірка роботи

- Створіть список через **+ Add new sheet**.
- Додайте задачу та позначте її виконаною.
- Перезавантажте сторінку: дані мають зберегтися.
- Змініть фон і перевірте його після перезавантаження.

Дані зберігаються в localStorage конкретного браузера та адреси сайту.
Інший порт або браузер матиме окреме сховище.
Очищення даних сайту видалить збережені списки й налаштування.
